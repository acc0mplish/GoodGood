## 프로세스와 작업 제어

프로세스 페이지는 같은 프로그램의 프로세스를 한 행으로 합친 앱 보기, 부모·자식 관계를 보여 주는 프로세스 트리, 모두 평면으로 나열하는 목록 보기를 제공합니다. 세 보기는 표시 방식만 다르고 정렬, 검색, 작업 제어를 공유합니다.

이름순으로 정렬하면 “앱”, “백그라운드 프로세스”, “Windows 프로세스” 세 범주로 나뉘고, 여러 사용자가 로그인한 동안에는 사용자별로 한 번 더 묶입니다. 범주와 사용자 그룹은 색으로 구분하고 접은 상태를 기억합니다.

열은 46개 속성 중에서 고릅니다. 표 머리글에서 마우스 오른쪽 단추로 클릭하면 여섯 하위 메뉴가 속성을 나열하고, “열 선택…” 대화 상자에서는 범주로 거르거나 이름과 설명으로 찾으며 끌어서 순서를 정합니다. 열 너비는 내용에 맞춰 자동으로 배분되고, 직접 조정한 열은 그 너비를 유지합니다.

행에서 마우스 오른쪽 단추로 클릭하거나 바로 가기로 다음 작업을 실행합니다.

| 작업 | 내용 |
|---|---|
| 작업 끝내기 | 프로세스 하나 또는 트리 전체를 끝냅니다. 앱 보기에서 그룹을 선택하면 그 그룹에 적용됩니다 |
| 우선 순위 | 실시간부터 낮음까지 여섯 단계 |
| I/O 우선 순위 | 매우 낮음, 낮음, 보통. 백그라운드 작업이 디스크를 채울 때 포그라운드 프로그램을 지킵니다 |
| 메모리 우선 순위 | 매우 낮음부터 보통까지. 메모리가 부족할 때 회수 순서를 정합니다 |
| 효율성 모드 | Windows가 그 프로세스를 E 코어와 낮은 주파수에 배치합니다 |
| 프로세스 일시 중단 | 모든 스레드를 멈추고 다시 시작할 때까지 유지합니다 |
| 규칙 추가 | 이후 그 프로그램이 시작할 때마다 같은 설정을 적용합니다 |

시스템 프로세스 숨기기는 프로세스 페이지와 연결 페이지가 스위치를 따로 두고 목록에만 적용합니다. 숨김 규칙은 “항상 표시”와 “추가로 숨기기” 두 목록으로 편집하고 실행 파일 이름으로 일치를 판단합니다.

“새 작업 실행…”은 어느 페이지에서나 열 수 있고 관리자 권한 실행을 선택할 수 있습니다. 바탕 화면을 호스팅하는 Windows 탐색기는 목록에서 “다시 시작”으로 되살립니다.

## 성능과 하드웨어

성능 페이지는 CPU, 메모리, 각 디스크, 네트워크 어댑터, GPU, 배터리를 장치별로 나열합니다. 장치 목록에서 항목을 숨기거나 끌어 순서를 바꾸고, 디스크는 디스크 번호순, 드라이브 문자순, 사용자 지정 중에서 정렬 기준을 고릅니다.

CPU는 전체 또는 다중 코어 보기로 봅니다. 다중 코어 보기는 논리 프로세서마다 작은 그림 하나를 빈자리 없이 배치하고, 하이브리드 아키텍처의 P 코어, E 코어, LP E 코어를 서로 다른 색으로 구분하며 유형별로 거를 수 있습니다. 사용률 곡선 아래에는 커널 시간을 겹쳐 그립니다.

CPU와 디스크는 “개요”와 “세부 정보”를 전환합니다. CPU 세부 정보는 프로세서 정보, 온도와 전력 곡선, 내부 센서, 코어별 표시값, 메인보드 센서, 패키지 제한과 유휴 상태를 카드로 나열하고, 디스크 세부 정보는 상태, 장치 정보, SMART 특성을 표시합니다.

GPU는 엔진 사용률을 기본값 “스마트”로 곡선 시간 범위 안에서 사용 중인 엔진만 나열합니다. 작은 그림은 격자, 집중, 목록 세 가지로 배치하고, 엔진 그림과 비디오 메모리 그림 사이의 구분선을 끌어 높이 비율을 조정합니다.

곡선은 창 크기에 맞춰 늘어나 실시간 숫자 바깥 공간을 채웁니다. 실시간 숫자와 사양은 넓은 창에서 좌우로 나란히 놓이고, 창이 좁으면 사양이 아래로 내려갑니다.

각 표시값의 출처와 적용 범위는 [하드웨어 데이터의 출처와 한계](hardware-data.md)에 있습니다.

## 기록

GoodGood이 실행되는 동안 5초마다 프레임 하나를 기록합니다. 시스템 전체 CPU, 메모리, 디스크와 네트워크 처리량, GPU, 배터리가 있는 장치는 충전 수준과 충전·방전 전력을 담고, 그 시점에 가장 사용량이 많았던 프로세스도 함께 남깁니다. 창을 최소화했거나 알림 영역에 숨겼거나 새로 고침을 일시 중지한 동안에도 기록합니다.

기록 페이지는 1시간, 6시간, 24시간, 7일 범위를 제공하고, 곡선의 임의 시점을 클릭하면 그때 가장 사용량이 많았던 프로세스가 아래에 나열됩니다. CPU 최대 프레임을 열면 그 최대값이 속한 실제 기록 프레임을 확인합니다. 기록은 이 PC에 7일 동안 보관하고 “설정 → 데이터 및 기록”에서 끄거나 지웁니다.

프로세스 하나를 골라 “이 인스턴스 관찰” 또는 “앞으로의 실행 관찰”을 실행하면 그 프로세스의 전용 작업 집합과 전용 커밋을 따로 기록합니다. 시스템 사용량 순위에 들지 못하는 프로세스도 이 관찰로는 기록됩니다.

## 서비스와 시작 프로그램

서비스 페이지는 서비스를 시작하고 중지하며 시작 유형을 바꿉니다. 프로세스 페이지의 `svchost`는 그것이 호스팅하는 서비스를 표시합니다. 상태 열의 머리글에서 전체, 실행 중, 중지됨을 거릅니다.

시작 프로그램 페이지는 레지스트리 Run 항목, 시작 폴더의 항목, 현재 계정에 설치된 앱 패키지 시작 작업을 나열하고 스위치로 사용 여부를 바꿉니다. 상태는 Windows 작업 관리자와 공유합니다.

두 페이지와 연결 페이지는 항목에 메모를 붙이거나 맨 위에 고정할 수 있습니다. 메모는 이름 뒤에 레이블로 표시되고 검색 대상에 들어가며, 고정한 항목은 목록 맨 앞에서 구분선 아래에 놓입니다. 메모와 고정은 다시 시작한 뒤에도 유지되고, 연결은 PID가 바뀌어도 같은 프로그램과 포트를 가리킵니다.

## 연결과 포트

연결 페이지는 TCP와 UDP 끝점, 소유 프로세스를 나열합니다. 포트로 정확히 검색하고 프로토콜과 상태로 거르며, IPv4 TCP 연결을 바로 끊습니다. 시스템 프로세스 숨기기는 PID가 0인 “소유 프로세스 없음” 기록도 함께 걸러 냅니다.

## 파일을 사용하는 항목

파일이나 폴더를 창에 끌어다 놓거나 “추가 작업” 메뉴에서 “파일을 사용하는 프로세스 찾기…”를 고르면 그 파일을 사용 중인 프로세스를 조회합니다. 결과는 다시 시작 관리자와 핸들 스캔 두 원본을 합치고, 하드 링크로 같은 파일을 연 경우를 파일 ID로 식별합니다.

사용 중인 프로세스가 바탕 화면의 탐색기이면 작업 단추가 “다시 시작”으로 바뀝니다. 결과는 접근할 수 없는 프로세스, 건너뛴 핸들, 시간 초과된 조회도 함께 나열하고, 한도에 이르면 부분 결과를 돌려줍니다.

## 알림 영역과 모니터

창을 닫으면 기본으로 알림 영역에 남고, Ctrl+Alt+Esc로 언제든 표시하거나 숨깁니다. 알림 영역 아이콘은 앱 아이콘, 추세, 비율, 숫자 중에서 고르고, 사용률이 80%에 이르면 호박색으로 바뀝니다.

마우스 올림 카드는 CPU, 메모리, GPU, 네트워크 값과 클릭 동작을 보여 주고, 마우스 오른쪽 단추로 클릭하면 빠른 패널이 열려 실시간 값과 사용량이 가장 많은 프로세스, 자주 쓰는 작업을 제공합니다.

데스크톱 모니터와 작업 표시줄 모니터는 선택한 표시값을 데스크톱의 작은 창과 작업 표시줄에 보여 줍니다. 표시값은 CPU, 메모리, GPU, 디스크, 네트워크, 배터리, 가동 시간에서 장치마다 고르고, 작업 표시줄 모니터는 레이블, 곡선, 캡슐, 큰 숫자 네 가지 스타일을 제공합니다. 세부 설정은 [상주 모드, 알림 영역과 바로 가기](resident-mode.md)에 있습니다.

## 화면 배치와 스크롤

설정 페이지는 창이 넓으면 카드를 두 열로 배치합니다. 카드 영역의 폭이 1080 논리 픽셀을 넘으면 설명이 두 줄 안에 들어가는 카드만 절반 폭을 차지하고 나머지는 한 줄을 모두 씁니다. 절반 폭 카드는 서로 짝을 이루어 배치하므로 빈 칸이 남지 않고, 창이 좁아지면 한 열로 돌아갑니다. 두 열은 같은 내용을 더 짧은 높이에 담으므로 스크롤이 줄어듭니다. 첫 실행 가이드, 정보 페이지, 구성 요소 페이지는 두 열을 쓰지 않습니다.

넘치는 목록과 대화 상자의 스크롤 막대는 Windows 11의 오버레이 방식으로 동작합니다. 평소에는 보이지 않다가 휠로 스크롤하거나 포인터를 손잡이에 올리거나 트랙을 누르는 동안 나타나고, 마지막 조작에서 1.2초가 지나면 250ms 동안 사라집니다. 손잡이는 포인터를 올리거나 끄는 동안 넓어집니다.

페이지와 대화 상자의 전환, 선택 표시의 이동, 아이콘 동작은 “설정 → 애니메이션 → 인터페이스 애니메이션”을 따릅니다. 이 설정을 끄면 전환과 스크롤 막대의 페이드 없이 바로 바뀝니다.

## 권한

표준 사용자도 모든 프로세스를 보고 대부분의 값을 읽습니다. 권한 있는 서비스는 시스템 프로세스 조작, 커널 센서, 작업 관리자 대체처럼 Windows가 관리자 권한을 요구하는 작업을 대신 수행합니다. 관리자 권한으로 실행하면 그 작업을 인터페이스 프로세스가 직접 처리합니다. 두 방식은 따로 켜고, 상태 표시줄이 현재 권한을 표시합니다.

커널 센서는 권한 있는 서비스와 PawnIO 드라이버를 통해 프로세서 내부 온도, 전압, 전력, 코어별 표시값을 보충합니다. 작업 관리자 대체는 Ctrl+Shift+Esc를 GoodGood으로 연결하고, 다른 대체 설정이 이미 있으면 덮어쓰지 않습니다. 설정 방법과 문제 해결은 [설정](settings.md#권한)에 있습니다.
