# 변경 기록

**한국어** · [English](en-US.md) · [Español](es-ES.md) · [Deutsch](de-DE.md) · [日本語](ja-JP.md) · [Français](fr-FR.md) · [Русский](ru-RU.md)

GoodGood 각 버전에서 사용자가 확인할 수 있는 변경 사항입니다. 버전 번호는 [유의적 버전](https://semver.org/lang/ko/)을 따릅니다. 이 파일이 원문이며, 다른 언어의 변경 기록은 이 파일을 항목별로 번역한 것입니다.

## [0.5.0](https://github.com/acc0mplish/GoodGood/compare/v0.4.0...v0.5.0) - 2026-11-12

v0.5.0에서는 프로세스 일시 중단과 다시 시작, 사용자별 프로세스 그룹, 프로세스 정보 열 네 가지와 내용에 맞는 열 너비를 추가했습니다. 성능 페이지의 장치 목록에서 장치를 숨기거나 순서를 바꿀 수 있습니다. 인터페이스는 이제 스페인어, 독일어, 일본어, 프랑스어, 러시아어를 지원합니다. 이번 버전에서는 GoodGood을 시작한 뒤 일부 Intel RST 시스템이 멈출 수 있는 요청을 피하고, USB 디스크의 안전한 제거를 막던 문제를 바로잡았으며, 창을 숨긴 상태의 메모리와 CPU 사용량을 줄였습니다.

### 기능

- **프로세스 일시 중단 및 다시 시작**: 프로세스와 앱 그룹 메뉴에서 "프로세스 일시 중단"과 "프로세스 다시 시작"을 사용할 수 있습니다. GoodGood은 중요한 시스템 프로세스, 데스크톱 창 관리자, 자기 자신의 일시 중단을 차단하며, 다른 프로세스를 일시 중단하기 전에 확인을 요청합니다. 일시 중단된 프로세스는 이름 뒤에 "일시 중단됨" 배지를 표시합니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#65](https://github.com/acc0mplish/GoodGood/pull/65))
- **프로세스 정보 열**: "파일 버전", "아키텍처", "권한 상승", "명령줄" 네 가지 선택 열을 추가했습니다. 기본값은 숨김입니다. 열 머리글 메뉴나 "열 선택"에서 사용하도록 설정합니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#72](https://github.com/acc0mplish/GoodGood/pull/72))
- **프로세스 열 너비**: 자동 너비는 내용에 맞추고 오른쪽에 사용하지 않는 공간을 남깁니다. 열 경계를 끌어 너비를 지정하거나 두 번 클릭하여 자동 너비로 되돌립니다. 새 "전체 너비" 옵션은 남은 너비를 이름 열에 줍니다.
- **사용자별 프로세스 그룹**: 설정 → 언어 및 모양 → 사용자별 프로세스 그룹에서 자동, 항상 그룹화, 그룹화 안 함 중에서 선택합니다. 자동을 선택하면 둘 이상의 사용자가 로그인한 경우에만 프로세스를 그룹화합니다. 프로세스 그룹 행의 상황에 맞는 메뉴에 "사용자 계정 관리"와 "로그아웃"이 있습니다.
- **시스템 프로세스 숨기기**: 프로세스 및 연결 페이지에 새 "시스템 프로세스 숨기기" 스위치가 있습니다. 기본값은 꺼짐이며 페이지마다 자체 설정을 유지합니다. 항상 표시할 프로그램과 함께 숨길 프로그램 목록은 설정 페이지에서 편집합니다. ([#32](https://github.com/acc0mplish/GoodGood/issues/32))
- **프로세스 트리 및 개요 밴드**: 프로세스 트리는 접힌 상태로 시작하며, 머리글 메뉴에 "모두 펼치기"와 "모두 접기"가 있습니다. "프로세스 개요 밴드"를 자동, 항상 표시, 숨김 중에서 설정합니다. 자동 모드에서는 창이 너무 낮으면 밴드를 숨깁니다.
- **성능 페이지의 장치 목록**: 장치를 마우스 오른쪽 버튼으로 클릭하여 숨기거나, "표시할 장치" 하위 메뉴에서 표시할 장치를 선택합니다. 장치를 끌어 순서를 바꿉니다. 디스크는 디스크 번호, 드라이브 문자 또는 사용자 지정 순서로 정렬할 수 있습니다.
- **CPU 다중 코어 보기**: 각 논리 프로세서 그래프에 커널 시간이 표시되며, CPU 그래프 메뉴에서 숨길 수 있습니다. GoodGood은 Intel 저전력 효율성 코어(LP E-코어)를 별도 색상과 필터로 구분합니다. 그래프는 가능한 경우 행을 가득 채웁니다.
- **하드웨어 정보**: GPU 페이지에 기능 수준을 포함한 드라이버 버전, 드라이버 날짜, DirectX 버전이 표시됩니다. 디스크 세부 정보는 더 많은 SATA SSD의 남은 수명과 총 읽기·쓰기 데이터를 지원합니다. HDD 통계에는 이제 전원 켜짐 시간, 시작/정지 횟수, 재할당된 섹터, 보류 중인 섹터가 포함됩니다.
- **인터페이스 언어**: 인터페이스는 이제 스페인어, 독일어, 일본어, 프랑스어, 러시아어를 지원합니다. 알림 영역, 시스템 메시지, 설치 관리자도 번역되었습니다. 숫자와 날짜는 Windows 지역 형식을 사용합니다. ([@abc0922001](https://github.com/abc0922001) [#45](https://github.com/acc0mplish/GoodGood/pull/45), [@Rimuwu](https://github.com/Rimuwu) [#51](https://github.com/acc0mplish/GoodGood/pull/51), [@s0ftw4r8](https://github.com/s0ftw4r8) [#52](https://github.com/acc0mplish/GoodGood/pull/52), [@khativari](https://github.com/khativari) [#55](https://github.com/acc0mplish/GoodGood/pull/55), [@hayxe1](https://github.com/hayxe1) [#62](https://github.com/acc0mplish/GoodGood/pull/62))
- **릴리스 정보**: 정보 페이지와 업데이트 대화 상자에 인터페이스 언어로 릴리스 정보가 표시됩니다. 설정 → 업데이트에서 "새로운 기능 보기"를 선택하면 대화 상자가 열리며, "모두 펼치기"와 "모두 접기" 컨트롤이 있습니다. 열기, 펼치기, 마우스 올림 전환은 "인터페이스 애니메이션" 설정을 따릅니다.
- **아이콘 및 움직임**: 인터페이스 아이콘은 이제 Lucide 아이콘 라이브러리를 사용합니다. 포인터가 단추나 탐색 항목 위로 이동하면 아이콘이 짧은 애니메이션을 한 번 재생합니다. "인터페이스 애니메이션"이 꺼져 있으면 애니메이션을 재생하지 않습니다.
- **창 및 알림 영역**: 별도의 "창 전환" 스위치를 사용할 수 있습니다. "알림 영역에서 다시 열기"로 기본 페이지를 열 수 있습니다. 기본 창 크기는 1000×680이고 최소 크기는 640×480입니다. ([#27](https://github.com/acc0mplish/GoodGood/issues/27), [#40](https://github.com/acc0mplish/GoodGood/issues/40))
- **작업 관리자 대체**: "작업 관리자 대체"에 새 "Windows 작업 관리자 한 번 열기" 단추가 있습니다. Windows 작업 관리자를 열며 대체 설정을 변경하지 않습니다.
- **공지 및 알림**: 포터블 버전은 시작 가이드와 창 오른쪽 아래에서 설치 버전과의 차이를 설명하고 다운로드 링크를 제공합니다. 새 "별표 알림"은 하루에 최대 한 번 표시되며 설정 → 업데이트에서 끌 수 있습니다. "내 PC" 위의 팁은 접을 수 있습니다.

### 성능

- **백그라운드 메모리 사용량**: 새 "숨길 때 메모리 확보" 설정은 창을 최소화하거나 알림 영역에 숨긴 상태로 설정한 시간(기본 10분)이 지나면 차트 이미지를 해제하고 사용하지 않는 메모리를 Windows에 반환합니다. 모든 창이 숨겨지거나 최소화되면 인터페이스의 CPU 사용량이 줄어듭니다. 샘플링, 기록, 규칙은 계속 실행됩니다. ([@SpookySandwich](https://github.com/SpookySandwich) [#54](https://github.com/acc0mplish/GoodGood/pull/54))

### 수정

- **시스템 멈춤**: GoodGood은 더 이상 Intel RST 같은 RAID 컨트롤러 뒤에 있는 디스크의 온도를 읽지 않습니다. 일부 드라이버 버전은 이 요청에 응답하지 않아 GoodGood을 시작한 뒤 몇 초 후 시스템이 멈출 수 있습니다. 이제 이 디스크의 온도는 알 수 없음으로 표시됩니다. ([#48](https://github.com/acc0mplish/GoodGood/issues/48))
- **USB 디스크의 안전한 제거**: 디스크 모니터링이 더 이상 USB 디스크를 사용 중으로 붙잡지 않으므로 Windows에서 안전하게 제거할 수 있습니다. ([#57](https://github.com/acc0mplish/GoodGood/issues/57))
- **디스크 목록 및 성능 데이터**: 일부 NVMe 디스크는 장치 정보만 표시하고 성능 데이터는 표시하지 않았습니다. 성능 카운터를 사용할 수 없을 때 디스크가 목록에서 사라지기도 했습니다. 두 가지 문제를 모두 수정했습니다.
- **디스크 세부 정보**: SMART 표는 값을 특성 이름 가까이에 유지하고 그룹 사이의 큰 간격을 없앴습니다. 원시 값은 좁은 창에도 들어갑니다. 상태 표시줄은 정상 값에 녹색을, 온도와 예비 용량에는 임계값에 따른 경고 색을 사용합니다.
- **프로세스 데이터**: 시스템 쿼리가 느릴 때 GoodGood은 프로세스 목록을 계속 갱신하고 마지막으로 유효한 리소스 표시값을 유지합니다. 종료된 프로세스는 더 이상 목록에 남지 않습니다. 새로 고침이 일시 중지된 상태에서도 프로세스 작업이 표시 상태를 갱신합니다. ([#66](https://github.com/acc0mplish/GoodGood/issues/66))
- **프로세스 표**: 효율성 모드와 고정 아이콘이 프로세스 이름 옆에 표시됩니다. 열 머리글이 데이터 열과 정렬됩니다. 프로세스 사용량 값에 퍼센트 기호가 포함됩니다.
- **연결 페이지**: 소유 프로세스가 없는 연결은 이제 "소유 프로세스 없음"으로 표시됩니다.
- **CPU 표시값**: 하이브리드 CPU가 이제 올바른 속도를 표시합니다. 일부 6코어 Ryzen 프로세서가 이제 올바른 코어별 전압과 온도를 표시합니다. Intel 내부 센서 표시값이 더 이상 간격을 두고 끊기지 않으며 온도 그래프도 끊기지 않습니다. ([#58](https://github.com/acc0mplish/GoodGood/issues/58))
- **권한 부여 및 제거**: Program Files나 런타임 폴더의 권한이 바뀐 뒤에도 GoodGood은 권한 부여를 취소하고 제거할 수 있습니다. 커널 센서는 이미 실행 중인 PawnIO 드라이버를 사용할 수 있습니다. 제거 후 "GoodGood Sensor Setup" 폴더와 빈 "GoodGood Runtime" 폴더가 남지 않습니다. ([#46](https://github.com/acc0mplish/GoodGood/issues/46))
- **시작 권한**: 설치나 앱 내 업데이트 후 GoodGood은 바로 가기로 실행할 때와 마찬가지로 데스크톱 계정의 권한으로 먼저 시작하려고 시도합니다. GoodGood이 관리자 권한으로 실행 중이면 이미 관리자 권한으로 실행 중인 파일 탐색기를 다시 시작하고 기존 권한을 유지할 수 있습니다.
- **창 표시**: 창 크기를 복원한 뒤 인터페이스가 다시 창을 채웁니다. 작업 관리자 대체 항목에서 콜드 스타트한 뒤 최대화된 창이 온전히 표시됩니다. Windows 11 21H2에서 창 배경이 더 이상 투명하지 않습니다. 다른 앱으로 전환한 뒤 GoodGood 창이 더 이상 다른 창 앞에 남지 않습니다. ([#44](https://github.com/acc0mplish/GoodGood/issues/44), [#37](https://github.com/acc0mplish/GoodGood/issues/37), [#35](https://github.com/acc0mplish/GoodGood/issues/35))
- **알림 영역**: 창을 알림 영역으로 닫은 뒤 CPU 사용량이 더 이상 높게 유지되지 않습니다. 앱 내 업데이트 후 알림 영역 아이콘이 위치를 유지하며 숨김 영역으로 밀리지 않습니다. ([#31](https://github.com/acc0mplish/GoodGood/issues/31))
- **인터페이스 표시**: 업데이트 대화 상자는 불러오는 동안 가운데를 유지하고, 파일 잠금 대화 상자는 결과가 나타날 때 제자리에 머뭅니다. 정보 페이지의 모든 내용은 낮은 창에서 스크롤하여 볼 수 있습니다. 텍스트 상자 상황에 맞는 메뉴는 인터페이스 언어를 사용합니다. ([#39](https://github.com/acc0mplish/GoodGood/issues/39))
- **숫자 및 렌더링**: 실시간 숫자는 갱신될 때 위치를 유지합니다. 어두운 배경 위의 밝은 텍스트는 가장자리가 바로잡혔습니다. 개요 밴드 아래에 작은 색상 잔여물이 더 이상 나타나지 않습니다.
- **안정성**: 디스플레이 타이밍이 유효하지 않거나 네트워크 어댑터 주소 쿼리가 여러 번 실패할 때 GoodGood이 더 이상 종료되지 않습니다. 그래픽 장치 복구와 창 닫기가 동시에 발생할 때 인터페이스가 더 이상 응답을 멈추지 않습니다.
- **큰 글꼴, 프로세스 규칙, 시작 항목**: 큰 글꼴 크기에서 성능 표시값이 더 이상 사양과 겹치지 않습니다. 프로그램 이름에 ASCII가 아닌 글자가 포함된 경우 프로세스 메뉴가 더 이상 중복 규칙을 추가하지 않습니다. 패키지 앱의 시작 작업을 읽을 때 GoodGood이 더 이상 강제 종료되지 않습니다. ([@hayxe1](https://github.com/hayxe1) [#59](https://github.com/acc0mplish/GoodGood/pull/59))
- **빌드 종류**: 설정, 정보, 상태 표시줄에 실행 중인 프로그램에 따라 "개발 빌드", "베타", "안정판"이 표시됩니다. 업데이트 채널은 이후 업데이트 확인에 사용할 소스를 별도로 선택합니다.

### 업그레이드

- **권한 있는 서비스**: 이번 버전은 서비스 통신 프로토콜을 버전 11로 업데이트합니다. 설치 관리자나 앱 내 업데이트로 업그레이드하면 설치된 서비스와 작업 관리자 대체 복사본도 함께 업데이트됩니다. 포터블 버전은 실행 파일을 교체한 후 설정 → 권한 → 권한 있는 서비스에서 "서비스 업데이트"를 선택하고 관리자 확인을 승인합니다.
- **설정 및 기록**: 업그레이드해도 설정과 기록이 유지됩니다. 처음 시작할 때 "창 전환"은 이전 "인터페이스 애니메이션" 옵션의 창 전환 설정을 사용합니다.

## [0.4.0](https://github.com/acc0mplish/GoodGood/compare/v0.3.4...v0.4.0) - 2026-11-06

v0.4.0은 애플리케이션 인터페이스를 Tauri, SolidJS, WebView2에서 네이티브 Rust + GPUI Kit 스택으로 이전하여 브라우저 엔진 오버헤드를 없애고 DirectX 렌더링과 상호 작용을 다시 구축했으며, 고주사율 애니메이션, 실시간 차트, 샘플링 갱신, 백그라운드 리소스 사용량을 최적화했습니다. 또한 사용자 지정 가능한 프로세스 열, 디스크 상태와 SMART 세부 정보, 확장된 Intel 내장 그래픽 표시값, 새로운 레이아웃 옵션을 추가했습니다. [GoodGood 웹사이트](https://goodgoodtask.com/en/)가 공개되었으며 공식 업데이트 미러도 함께 제공됩니다.

### 기능

- **사용자 지정 가능한 프로세스 열**: 일반, CPU, 메모리, 디스크 및 I/O, 네트워크, GPU의 6개 범주에 걸친 40개 열 중에서 선택할 수 있으며, 전용 및 공유 GPU 메모리, GPU 엔진, 이미지 이름, 가상 주소 공간, 최대 작업 집합, 페이지 오류, 총 I/O 카운터를 포함합니다. 가상 주소 공간과 최대 작업 집합은 프로세스별로 표시됩니다. 열 머리글을 마우스 오른쪽 버튼으로 클릭하면 범주 하위 메뉴 전체에서 열을 연속으로 전환할 수 있고, 2열 "열 선택" 대화 상자에서 범주별 필터, 검색, 순서 변경을 할 수 있습니다. 머리글이나 선택한 열을 끌면 부드러운 전환과 함께 실시간으로 순서가 바뀝니다. 자동 너비는 숫자 형식에 따라 공간을 확보하여 흔들림을 방지하고, 수동 너비도 저장됩니다. 평면 목록과 프로세스 트리 보기의 이름 열은 이제 앱 보기와 마찬가지로 애플리케이션 이름이나 파일 설명을 먼저 표시하고, 실행 파일 이름은 옆이나 이미지 이름 열에 표시합니다.
- **디스크 상태 및 세부 정보**: 디스크 성능 보기에 개요 / 세부 정보 전환이 추가되어 NVMe, ATA/SATA, USB-SAT, SCSI/SAS 장치 정보를 필요할 때 읽어 상태, 남은 수명, 온도와 임계값, 전원 켜짐 시간과 횟수, 총 읽기·쓰기 바이트, 미디어 및 읽기/쓰기 오류 카운터, PCIe 링크 속도, SMART 특성을 표시하며 수동 새로 고침을 지원합니다. 일련 번호는 프로토콜이 보고한 공급업체 식별자를 우선하며 기본적으로 숨겨집니다.
- **시스템 개요 및 성능 차트**: 프로세스 페이지의 개요 카드를 새로 디자인하여 왼쪽 숫자 아래로 사라지는 가장자리까지 이어지는 곡선을 그리고 위쪽에 눈금 한계를 표시하며 마우스를 올리면 카드 전체를 강조합니다. 또한 CPU 온도, CPU 전력, GPU 전력 표시값을 추가했습니다. CPU 개요 페이지는 패키지 전력과 코어 전력을 하나의 "전력" 표시값으로 합치고(패키지 전력 우선, 마우스를 올리면 출처 표시, 두 곡선은 모두 세부 정보 페이지에 유지), 디스크와 네트워크 차트는 고정 단계로 눈금을 조정하며, 사이드바의 소형 미리 보기 차트는 보조 계열을 반투명 실선으로 그려 작은 크기에서도 가독성을 높입니다.
- **Intel 내장 그래픽**: 드라이버가 보고하는 온도, 클록, 전압, 전력 표시값을 확장하고, 커널 센서(IntelMCHBAR 모듈)와 RAPL PP1을 통해 10세대 Core(Comet Lake S/H) 내장 그래픽의 온도, 클록, 공유 메모리 클록, 코어 VID, GT/미디어 활동, 전력을 추가했습니다. 그래픽 슬라이스 클록 게이팅을 활성 클록과 구분하고, 1 W 미만의 와트 단위 전력도 표시하며, 내장 그래픽 전력은 해당 GPU 페이지에 배치합니다. 유효한 RAPL 전력 표시값은 Windows 전원 카운터가 보고하는 0 값보다 우선합니다. 하드웨어나 드라이버가 제공하지 않는 값은 알 수 없음으로 표시됩니다.
- **창 및 레이아웃**: 설정 → 시작 프로그램 및 알림 영역에서 실행할 때 열 기본 페이지를 선택합니다. 펼친 측면 탐색의 오른쪽 가장자리를 끌어 너비를 조정하고 두 번 클릭하면 기본 너비로 돌아갑니다. 새 "프로세스를 선택하면 표시" 세부 정보 창 모드를 사용하면 프로세스를 선택할 때 창이 밀려 나오고 선택을 해제하면 숨겨집니다. 기록 페이지에서 시간 범위를 바꾸면 항상 현재까지의 최신 구간이 표시됩니다. 최소 창 크기는 전체 레이아웃을 유지하기 위해 1240×800이며, 기본 디스플레이의 작업 영역이 더 작으면 자동으로 줄어듭니다.
- **정보 페이지, 릴리스 정보, 공식 미러**: 정보는 이제 GoodGood 웹사이트와 GitHub 리포지토리 링크 카드가 있는 별도 탐색 페이지(Ctrl+8)입니다. 상태 표시줄 왼쪽의 버전 배지를 클릭하면 현재 버전의 릴리스 정보가 열리고 마우스 오른쪽 버튼으로 클릭하면 버전이 복사됩니다. 릴리스 정보는 범주별로 묶이며 새 기능은 2열 카드 그리드로 배치됩니다. 자동 업데이트는 GitHub에 연결할 수 없을 때 공식 GoodGood 미러를 먼저 시도한 후 GitHub 프록시로 넘어가며, 설치 관리자와 릴리스 정보의 서명은 이전과 같이 확인합니다.

### 성능

- **인터페이스 응답성 및 고주사율 애니메이션**: 샘플링 갱신, 텍스트 측정, 반복 그리기에서 발생하는 메인 스레드 오버헤드를 줄이고, 정적 차트 배경과 컴포지션 레이어를 재사용하며, 큰 차트 텍스처의 래스터화를 여러 스레드로 병렬 처리하고, 하드웨어 가속 GPU 예약(HAGS)이 꺼져 있을 때 차트 GPU 사용량을 크게 줄였습니다. 페이지 전환, 세부 정보 창, 목록 스크롤, 열 순서 변경은 디스플레이 주사율로 애니메이션되고, 다중 코어 그리드와 GPU 엔진 차트는 창과 같은 프레임에서 크기가 바뀝니다.
- **페이지 전환 및 백그라운드 작동**: 서비스, 시작 프로그램, 연결 목록은 시작 후 백그라운드에서 미리 로드되어 처음 방문할 때 즉시 표시됩니다. 인터페이스 환경 설정은 모아서 백그라운드에서 비동기로 기록하여 페이지 전환 지연을 없앴습니다. 실시간 차트가 없는 페이지는 샘플마다 반복 재구성을 건너뛰어 CPU 사용량을 낮춥니다. 창을 최소화하거나 알림 영역에 숨긴 동안 그리기를 멈추고 필요에 따라 차트 레이어 캐시, 만료된 아이콘, 텍스처 아틀라스를 회수하여 백그라운드 메모리와 GPU 메모리 오버헤드를 줄입니다.
- **높은 부하 및 낮은 메모리**: 알림 영역 갱신은 전용 스레드에서 모아 처리하여 시스템이나 셸이 바쁠 때 응답성을 높입니다. 메모리가 부족하면 차트가 자동으로 버퍼를 줄이고 텍스처 해상도를 낮춰 실시간 곡선을 계속 유지하며, 메모리가 회복되면 전체 품질로 돌아갑니다. 창을 활성화하면 큰 최상위 창이 가로막을 때 더 효과적으로 처리합니다.

### 수정

- **프로세스별 네트워크 트래픽**: 일부 컴퓨터에서 표시값이 0으로 유지되던 문제와, 0.5초 새로 고침 간격에서 0 값과 실제 값이 번갈아 나오거나 갱신이 지연되던 문제를 수정했습니다.
- **권한 있는 서비스**: 클라이언트가 파이프 연결이 완료되기 전에 끊길 때 서비스가 예기치 않게 종료되던 문제와, 빈번한 읽기 중 시간 초과나 잘못된 데이터 없음 결과가 나오던 문제를 수정했습니다.
- **애플리케이션 이름 및 아이콘**: 패키지(MSIX) 앱이 작업 관리자에 표시되는 애플리케이션 이름 대신 실행 파일 설명을 표시하던 문제와, 장치 경로 매핑을 사용할 수 없거나 프로세스가 접근을 거부할 때 아이콘이나 파일 설명이 누락되던 문제를 수정했습니다.
- **프로세스별 GPU 메모리**: 프로세스와 물리 어댑터별로 중복을 제거한 상주 GPU 메모리 카운터로 전환하여 일부 시스템과 드라이버에서 표시값이 부풀거나 두 번 계산되던 문제를 수정하고, 사용할 수 없는 표시값과 0 사용량을 구분했습니다.
- **Intel 내장 그래픽 전력 표시**: CPU 개요 페이지에서 유휴 상태의 내장 그래픽 전력이 반복해서 나타났다 사라지던 문제를 수정했습니다.
- **CPU 가상화 상태**: 하드웨어 가상화가 켜진 Hyper-V 호스트가 계속 "사용 안 함"으로 표시되던 문제를 수정했습니다.
- **관리자 시작 권한 부여**: 사용자 이름이 컴퓨터 이름과 같을 때 SID 확인이 실패하던 문제를 수정하고, 같은 버전의 재구축된 복사본을 감지하는 기능을 개선했습니다.
- **장시간 사용 시 메모리 사용량**: 프로그램 아이콘을 내용으로 중복 제거하고, 종료된 프로그램 경로에 캐시된 메타데이터를 주기적으로 정리하며, 메타데이터 확인 작업이 바쁠 때 대기 중인 요청 수를 제한하여, 새 경로에서 수명이 짧은 프로그램이 많이 실행될 때 메모리가 계속 늘어나던 문제를 수정했습니다.
- **외부 링크**: 외부 웹 링크(웹사이트, 리포지토리, 릴리스 페이지)를 열 때 중간 Explorer 프로세스를 만들지 않고 URL을 시스템 셸에 직접 넘겨 브라우저 실행 지연을 없앴습니다.

- **권한 있는 서비스**: 이번 버전은 서비스 프로토콜을 버전 10으로 업데이트합니다. 설치 관리자나 앱 내 업데이터로 업그레이드하면 설치된 서비스와 작업 관리자 대체 복사본도 함께 업데이트됩니다. 포터블 실행 파일을 교체한 후 설정 → 권한 → 권한 있는 서비스에서 "서비스 업데이트"를 선택하고 관리자 확인을 완료합니다.

- **글꼴 크기**: 기본 글꼴 크기를 11에서 20 px 사이로 조정합니다(기본값: 13 px). 인터페이스 배율과 함께 적용되며 즉시 반영되고 자동으로 저장됩니다. 각 설정은 따로 초기화할 수 있습니다.

### 수정

- **GPU 통계**: 일부 컴퓨팅 작업에서 전체 사용량이 낮게 표시되던 문제, 샘플링이 다시 시작될 때 값이 튀는 문제, GPU나 엔진이 여러 개일 때 합계가 부풀던 문제를 수정하려고 시도했습니다. 프로세스 엔진 카운터와 사용 가능한 NVIDIA GPU 코어 사용률로 전체 사용량을 보완하며, 출처는 인터페이스에 표시됩니다. ([#19](https://github.com/acc0mplish/GoodGood/issues/19))
- **창 복원**: 프로그램을 종료한 뒤 다시 열면 창 크기, 위치, 최대화 상태가 복원됩니다. 최소화된 상태로 종료해도 다음 실행이 최소화된 채로 남지 않으며, 화면 밖에 있던 창은 사용 가능한 디스플레이 영역으로 돌아옵니다.
- **목록 환경 설정**: 프로세스, 서비스, 시작 프로그램, 연결 목록이 정렬 열과 방향을 기억합니다. 서비스와 연결은 선택한 필터도 복원합니다.
- **환경 설정 저장**: 인터페이스 환경 설정은 별도로 저장되며 이전 캐시에서 자동으로 이전됩니다. 인터페이스 캐시를 지운 뒤에도 저장된 환경 설정을 사용할 수 있습니다.
- **레이아웃 및 창 컨트롤**: 글자가 크거나 배율이 높은 좁은 창에 맞춰 도구 모음과 탐색이 조정되고, 최대화 단추의 클릭 영역이 배율을 올바르게 따릅니다.

### 업그레이드

- v0.3.x에서 업그레이드하면 기존 설정과 기록이 유지됩니다. 이전 인터페이스 환경 설정은 처음 실행할 때 자동으로 이전되며 직접 다시 설정할 필요가 없습니다.

### 호환되지 않는 변경 사항

- **권한 있는 서비스를 업데이트해야 합니다**: 이번 버전은 GoodGood이 권한 있는 서비스와 통신하는 방식을 변경했으며 0.1.0 서비스는 새 버전과 함께 작동하지 않습니다. 권한 있는 서비스를 설치하지 않았다면 달라지는 점은 없습니다.
- **설치 관리자로 업그레이드**: 앱 내 업데이트와 직접 설치 관리자를 실행하는 경우가 모두 해당됩니다. 설치 관리자는 작업 관리자 대체로 시작되어 아직 실행 중인 이전 GoodGood을 먼저 닫고 같은 관리자 승인으로 권한 있는 서비스를 업데이트하므로 따로 할 일이 없습니다. 작업 관리자 대체가 켜져 있으면 그대로 유지되며, 업데이트 후 Ctrl+Shift+Esc는 새 버전을 엽니다.
- **포터블 버전 업그레이드**: 권한 있는 서비스를 설치한 경우 프로그램을 교체한 뒤 서비스를 직접 업데이트합니다. 새 GoodGood의 공지나 설정 → 권한에서 서비스 업데이트를 클릭하고 승인합니다. 설치 관리자가 서비스 업데이트에 실패한 경우에도 같은 방법을 사용합니다. 서비스를 업데이트할 때까지 이에 의존하는 네트워크, 디스크 읽기/쓰기, CPU 센서 데이터를 사용할 수 없으며 관리자 권한이 필요한 관리 작업이 실패할 수 있습니다. 작업 관리자 대체가 켜져 있으면 Ctrl+Shift+Esc가 계속 이전 버전을 열 수 있으며, 서비스를 업데이트하면 대체도 함께 업데이트되고 켜진 상태가 유지됩니다.

### 기능

- **프로세스별 디스크 읽기 및 쓰기**: 프로세스 페이지에 디스크 읽기와 디스크 쓰기 두 개의 새 열이 추가되어 각 프로세스가 초당 디스크에서 읽고 쓰는 데이터 양을 표시합니다. 두 열 모두 정렬할 수 있고 앱별로 프로세스를 그룹화하면 그룹 합계를 표시하며 세부 정보 패널에도 나타납니다. I/O 열은 네트워크와 장치 트래픽도 계산하므로 두 열과 구분해서 유지됩니다. Windows 11 24H2 이상은 추가 권한이 필요 없고, 이전 버전은 권한 있는 서비스나 관리자 권한으로 실행하는 GoodGood이 필요하며 권한 있는 서비스의 승인 화면에 이 내용이 표시됩니다. 아직 표시값이 없을 때는 두 열에 "—"가 표시되며 마우스를 올리면 이유를 설명합니다. 좁은 창에서는 이 두 열이 항상 유지되고 표가 옆으로 스크롤되며 이름 열이 왼쪽에 남으므로, 스레드, 핸들, PID, I/O 열은 이전보다 일찍 숨겨집니다.
- **앱 내 업데이트**: 이번 버전부터 새 버전을 내려받아 서명 확인을 통과하면 제목 표시줄 오른쪽에 업데이트 단추가 나타나고 알림 영역 아이콘에 점이 표시되며, 오른쪽 아래에 버전마다 한 번씩 공지가 표시됩니다. 포터블 버전은 업데이트를 내려받지 않고 새 버전을 찾으면 바로 알려 줍니다. 업데이트 대화 상자에는 현재 버전과 새 버전 사이의 모든 버전 변경 사항이 범주별로, 각 범주의 변경 수와 함께 표시되며 정보는 설치 관리자와 마찬가지로 서명을 확인합니다. 업데이트 단추를 마우스 오른쪽 버튼으로 클릭하면 "이 버전에 대해 다시 알리지 않음"을 선택할 수 있습니다. 내려받은 업데이트는 GoodGood을 다시 시작한 뒤 다시 내려받을 필요가 없습니다.
- **업데이트 후 새로운 기능**: 업데이트 후 창을 처음 열면 새 버전에서 달라진 점이 표시됩니다. 이 기능을 끄려면 설정 → 업데이트에서 "업데이트 후 새로운 기능 표시"를 사용하며, 이후에는 오른쪽 아래 공지만 표시됩니다. 같은 페이지의 "이 버전의 변경 사항 보기"는 언제든지 정보를 엽니다.
- **백그라운드 새로 고침 빈도**: 최소화 상태와 알림 영역에 있을 때의 새로 고침 빈도를 설정 → 데이터 및 기록과 처음 실행 안내에서 각각 0.5초에서 30초 사이로 설정할 수 있습니다(기본값 5초). 5초 미만이면 CPU 사용과 전력 소모가 늘어난다는 설명이 먼저 표시되고, 5초를 넘으면 기록도 더 드물게 저장됩니다. 창이 다시 앞으로 나오면 GoodGood은 즉시 새로 고침합니다. 백그라운드 빈도가 포그라운드보다 느리면 오른쪽 아래에 공지가 한 번 표시되며 설정으로 가는 바로 가기와 다시 표시하지 않는 옵션이 있습니다.
- **바로 가기 설정**: 키를 유지한 채 바로 가기를 끌 수 있고 다시 켜면 복원됩니다. 기록 중에는 누르고 있는 키가 실시간으로 표시되고, 사용할 수 없는 조합은 이유가 설명되며 "기본값 복원"을 사용할 수 있습니다. Ctrl+글자나 Alt+글자처럼 다른 프로그램과 충돌하기 쉬운 조합은 확인한 뒤에만 저장됩니다. 다른 프로그램이 조합을 점유하고 있으면 바로 다시 시도할 수 있고, 해당 프로그램이 종료되면 창을 다음에 표시할 때 GoodGood도 다시 시도합니다.
- **CPU 가동 시간**: 초 단위까지 표시되며(예: "5일 14:03:07") 새로 고침할 때마다 갱신됩니다.

### 수정

- **강제 종료**: 사용할 수 있는 Intel 그래픽 어댑터가 없는 일부 PC에서 한동안 실행한 뒤 GoodGood이 강제 종료될 수 있던 문제를 수정했습니다.

- **Windows와 함께 시작**: GoodGood은 Windows와 함께 시작할 때 더 이상 포그라운드를 가져가지 않습니다. 이전에는 다른 곳을 클릭할 때까지 키 입력이 보이지 않는 GoodGood 창으로 전달되었습니다. 알림 영역에 숨겨진 동안 인터페이스가 백그라운드에서 계속 그리지 않으므로 CPU와 GPU 사용량이 크게 줄고 메모리 사용량이 절반 이상 줄어듭니다.

- **백그라운드 새로 고침**: 최소화 상태나 알림 영역에 있을 때의 새로 고침 빈도가 이제 설정과 일치합니다. 이전에는 5초로 설정해도 6초인 경우가 많았고 때로는 10초였습니다. 권한 있는 서비스와 함께 표준 사용자로 실행할 때 알림 영역이나 최소화 상태에서 창을 복원한 뒤 프로세스 페이지의 네트워크 열이 잠시 사라지지 않습니다.
- **창**: 최대화했을 때 오른쪽 위 모서리에 겹치는 단추 두 벌이 나타나지 않으며, 화면 맨 위에서도 포인터로 창을 끌 수 있습니다.
- **설치 관리자 및 제거 관리자**: 완료 페이지의 닫기 단추, 제거 확인 페이지의 취소 단추, 확인란 행이 이제 가운데에 정렬됩니다. 이전에는 조금 왼쪽으로 치우쳐 있었습니다.
- **설치 관리자로 업그레이드**: 업그레이드를 위해 설치 관리자를 실행하면 Ctrl+Shift+Esc나 이전 시작 항목으로 열려 아직 실행 중인 이전 GoodGood도 닫히므로, 업그레이드 후의 시작이 이전 버전으로 넘어가지 않습니다. 먼저 알림 영역에서 종료할 필요가 없습니다.
- **제거**: 제거할 때 Ctrl+Shift+Esc로 열려 아직 실행 중인 GoodGood도 닫힙니다. 이전에는 백그라운드에 남아, "설정, 기록, 로그도 삭제"로 제거한 뒤 다시 설치하면 첫 실행에서 시작 가이드가 생략되고 이전 설정이 다시 기록되었습니다. 일부 데이터를 삭제하지 못한 경우 제거 관리자가 남은 폴더를 나열합니다.
- **처음 실행 안내**: Ctrl+Shift+Esc를 눌러 GoodGood을 열 때 누르고 있던 Esc로 안내가 닫히고 완료로 표시되던 문제를 수정했습니다.
- **바로 가기 기록**: 기록 중에 현재 조합을 누르거나 키를 조금 더 오래 누르고 있어도 실수로 창이 숨겨지지 않습니다. 미국 영어 외의 키보드 배열에서도 기록한 키가 바로 가기를 실행하는 키와 일치합니다. Shift+Backspace와 Win+Backspace로 실수로 바로 가기가 지워지지 않습니다.

- **바로 가기**: 일부 숫자 키패드 키가 다른 키로 등록되지 않습니다. 바로 가기를 변경하는 중에 설정 저장이 실패해도 제거할 수 없는 추가 바로 가기가 남지 않습니다. 등록 실패 이유는 인터페이스 언어로 표시됩니다. 처음 실행 안내에서는 이미 사용 중이거나 사용할 수 없는 바로 가기의 이유만 표시되고 설정에서 변경할 수 있다는 점을 안내합니다.
- **작업 관리자 대체**: 권한 있는 서비스를 업데이트하면 먼저 Windows 작업 관리자를 복원하고 업데이트 후 다시 켜야 했던 방식 대신, 대체를 켠 상태로 유지하고 사용하는 GoodGood을 새 버전으로 업데이트합니다. 켜기에 실패하면 GoodGood이 어느 단계가 거부되었는지와 그 이유(예: 보안 소프트웨어가 레지스트리 변경을 차단)를 알려 줍니다. 상태가 "다른 항목으로 구성됨"으로 표시되면 관련된 설정을 나열합니다. 대체를 끈 뒤 Process Explorer 같은 다른 도구가 작업 관리자를 대신해도 권한 있는 서비스의 업데이트나 제거를 방해하지 않습니다. 실패한 시도가 서비스 폴더에 GoodGood 복사본을 남기지 않으며, 이전 버전이 남긴 복사본은 업그레이드하거나 대체를 켜거나 끌 때, 또는 권한 있는 서비스를 업데이트하거나 제거할 때 실행 중이 아니라면 정리됩니다.
- **프로세스**: 아무것도 선택하지 않은 상태에서 "세부 정보 표시"를 클릭하면 이전처럼 아무 일도 일어나지 않고 이제 목록에서 항목을 먼저 선택하라는 메시지가 표시됩니다. 상황에 맞는 메뉴나 확인 창이 열려 있는 동안 상태 표시줄에 "포인터가 목록 위에 있어 정렬이 일시 중지됨"이 표시되지 않고, 확인 창이 나타날 때 목록이 다시 정렬되지 않습니다. 포인터가 목록 위에 있는 상태에서 바로 가기로 페이지를 전환해도 다른 페이지의 상태 표시줄에 그 메시지가 남지 않습니다.
- **차트**: 차트 오른쪽 가장자리 근처에서 포인터를 움직여도 마우스 올림 점이 끊기지 않습니다.
- **업데이트 채널 전환**: 업데이트를 확인하거나 내려받는 중에 안정판과 베타 사이를 전환하면 이전 채널의 버전을 제안하지 않고 새 채널에서 다시 확인합니다.
- **진단 로그**: 실패가 일반적인 "작업 실패" 대신 시스템 오류 코드와 함께 기록됩니다. 이전에는 영어가 아닌 시스템에서 거의 모든 실패가 일반 메시지로 기록되었습니다. 시작할 때 권한 있는 서비스에 연결하지 못한 이유(예: 호환되지 않는 버전이나 시간 초과)도 로그에 기록됩니다.

### 성능

- **프로세스 페이지**: 시스템 개요의 프로세서별 소형 사용량 막대를 그리는 비용을 줄였습니다. 차트가 움직이는 동안 인터페이스가 매 프레임 그래픽 카드로 보내는 데이터가 약 3분의 1 줄어들며, I/O 열에서 WebView2의 읽기와 쓰기 대부분이 이 데이터에서 발생하므로 그 수치도 함께 줄어듭니다.

### 알려진 문제

- **디스크 읽기 및 쓰기**: Windows 11 24H2 이상에서 사용하는 방식은 빌드 26300에서만 확인했습니다. 이전 버전은 권한 있는 서비스나 관리자 권한으로 읽으며 아직 확인하지 못했습니다. 두 열에 항상 "—"가 표시되면 진단 로그를 첨부하여 알려 주십시오. 로그에 읽기 실패 이유가 기록됩니다.
- **코드 서명**: 프로그램에 아직 코드 서명이 없으므로 처음 실행할 때 Windows SmartScreen이 "알 수 없는 게시자"를 경고할 수 있습니다.
- **기타**: 다른 알려진 문제는 GitHub의 [알려진 문제](https://github.com/acc0mplish/GoodGood/blob/main/docs/known-issues.md) 페이지에서 확인할 수 있습니다.

## 0.1.0 - 2026-10-16

GoodGood의 첫 공개 버전입니다.

### 기능

- **프로세스**: 앱별, 프로세스 트리, 목록 형태로 볼 수 있으며 이름으로 정렬하면 목록이 앱과 백그라운드 프로세스로 나뉩니다. 각 프로세스에 CPU, 메모리, I/O, GPU 사용량이 표시되고, 권한 있는 서비스를 사용하거나 관리자 권한으로 실행하면 네트워크 트래픽도 표시됩니다. 검색하고 프로세스나 프로세스 트리 전체를 끝낼 수 있으며, 세부 정보 패널에서 명령줄, 사용자, 무결성 수준 등을 확인할 수 있고 앱별로 그룹화하면 앱 전체의 합계도 표시됩니다.
- **우선 순위 및 효율성 모드**: 상황에 맞는 메뉴에서 설정하거나 프로그램이 시작될 때마다 적용되는 규칙으로 설정합니다.
- **성능**: CPU(코어별, 성능 및 효율성 코어, 주파수, 온도, 전력, 유휴 상태), 메모리, 디스크, 네트워크, GPU(NVIDIA, AMD, Intel 그래픽의 와트 단위 전력 포함), 배터리를 표시합니다. 차트는 디스플레이 주사율에 맞춰 흐르고 창 크기에 따라 조정되며, 사용 빈도가 낮은 세부 정보는 펼칠 수 있는 카드에 배치됩니다.
- **커널 센서(선택 사항)**: 설정이나 처음 실행 안내에서 켜면 GoodGood이 권한 있는 서비스와 공식 PawnIO 드라이버를 통해 CPU 내부 센서를 읽으며, 코어별 온도와 전압, 전력과 제한 상태, AMD SMU 데이터, 지원되는 메인보드의 팬 속도, 전압, 온도를 포함합니다.
- **서비스 및 시작 프로그램**: 서비스를 시작하고 중지하며 시작 유형을 변경합니다. Windows 작업 관리자와 같은 스위치로 시작 프로그램을 사용하거나 사용 안 함으로 설정합니다.
- **연결 및 포트**: TCP와 UDP 끝점과 이를 소유한 프로세스, 포트로 정확히 검색하기, IPv4 TCP 연결 닫기를 제공합니다.
- **파일 잠금**: 창에 파일이나 폴더를 끌어 놓으면 Restart Manager와 핸들 열거를 통해 해당 항목을 사용하는 프로세스를 찾으며, 현재 폴더가 그 항목인 프로세스도 포함됩니다.
- **기록**: 최근 7일의 리소스 사용량이 기록되며, 임의의 시점을 클릭하면 그때 가장 많이 사용한 프로세스를 볼 수 있습니다.
- **알림 영역**: 전역 바로 가기 Ctrl+Alt+Esc로 창을 표시하거나 숨깁니다. 숨긴 동안 GoodGood은 리소스를 거의 사용하지 않습니다.
- **선택적 권한 있는 서비스**: 한 번 관리자 승인을 받으면 인터페이스는 표준 사용자로 실행되면서도 시스템 프로세스를 관리하고, 규칙을 자동으로 적용하고, 프로세스별 네트워크 트래픽을 추적하고, 서비스를 제어하고, 연결을 닫을 수 있습니다.
- **작업 관리자 대체**: Ctrl+Shift+Esc와 작업 관리자를 여는 다른 방법으로 GoodGood을 열 수 있으며, 인터페이스와 서비스 어느 쪽에도 의존하지 않는 별도의 복구 도구를 제공합니다.
- **앱 내 업데이트**: 안정판과 베타 채널, 선택적 GitHub 다운로드 미러를 제공하며 서명 확인을 통과한 버전만 설치합니다.
- **모양**: 도구 모음이 제목 표시줄을 겸하고 탐색은 도구 모음 아래나 창 왼쪽에 위치합니다. Mica 배경과 시스템 강조 색을 사용하며 밝은 테마와 어두운 테마는 기본적으로 Windows를 따르거나 설정에서 선택할 수 있습니다.
- **설치 및 제거**: Windows의 밝은 모드와 어두운 모드를 따르는 한 페이지 설치 관리자를 제공합니다. 설치된 이전 버전은 그 자리에서 업그레이드되며 제거할 때 설정, 기록, 로그도 삭제할 수 있습니다.
- **언어 및 처음 실행 안내**: 인터페이스, 알림 영역, 설치 관리자는 한국어와 영어를 지원하며 기본적으로 Windows 표시 언어를 따릅니다. 처음 시작할 때 안내가 언어, 표시, 새로 고침, 알림 영역, 업데이트 등 일반적인 설정을 차례로 안내하며, 선택적 권한 있는 서비스 설치, 커널 센서 켜기, 작업 관리자 대체를 바로 설정할 수 있습니다.
