# 첫 페이지 실측 데이터

## Windows 조작 소요 시간

`windows-interaction.json`은 실제 PC에서 측정한 회차별 소요 시간(밀리초)을 저장하고, `windows-test-machine.json`은 시스템, 프로그램 버전, 창 크기와 측정 조건을 기록합니다. 첫 페이지는 도구와 조작별로 중앙값을 계산해 GoodGood과 시스템 작업 관리자를 비교하며, 원본 데이터는 `/benchmarks/windows-interaction.json`으로 제공합니다.

탭 전환 측정은 마우스 클릭 시점부터 대상 창 본문이 처음 일치하는 Windows Graphics Capture 프레임까지를 잽니다. 각 방향은 예열한 뒤 번갈아 두 차례 측정하며 한 차례에 8회입니다. CPU 비교는 모두 논리 프로세서 20개를 표시하는 보기를 사용합니다. 프로세스 목록 시험은 GoodGood 목록과 작업 관리자의 세부 정보 페이지를 각각 사용합니다. PID 오름차순과 내림차순에 대해 각각 6회 조작을 한 묶음으로 수행하고, 본문에 실제로 표시된 PID로 방향을 확인합니다. 순서를 고정한 뒤에는 두 프로세스 행을 번갈아 선택하며 모두 12회입니다.

## 첫 페이지 창 시연

첫 페이지 창 시연의 시스템 판독값은 가상의 값입니다. 표본 번호에 따라 결정적 잡음으로 생성하며(빠르기와 느리기가 다른 여러 물결에 이따금의 부하 급증을 더함), 되풀이되지 않고 서버와 브라우저가 만든 첫 프레임이 일치합니다. 각 프로세스는 가중치에 따라 같은 시각의 시스템 합계를 나누어 가지며, 열 합계는 시스템 전체 판독값과 일치합니다. 프로세스, 서비스, 시작 항목과 연결은 가상의 시연 데이터이고 주소는 문서용 주소 대역을 사용합니다.

## 프로젝트 후원 & 특별 감사

`supporters.json`은 첫 페이지의 오픈 소스 구역과 각 언어 README의 감사 부분에 표시하는 후원자를 나열하며, 후원자마다 카드 한 장을 만듭니다. 항목은 `id`, 닉네임 `name`, 홈페이지 링크 `url`이고, 아바타는 `supporters/<id>.webp`(256 픽셀 정사각형)입니다. 후원자를 추가하거나 고친 뒤에는 `node scripts/supporters.mjs`를 실행합니다. 이 스크립트는 아바타에서 색을 뽑아 `colors`(첫 페이지 카드의 밝은 테마와 어두운 테마 조명 색)에 쓰고, Great Vibes 손글씨체로 닉네임을 벡터 윤곽으로 바꿔 `signature`(100 픽셀 글자 크기에서의 경로와 잉크 범위, 첫 페이지 카드와 README 카드가 함께 사용하며 글꼴에 없는 글자는 생략하고 카드는 보통 글자로 표시)에 쓰며, `docs/images/supporters/`에 언어별·테마별 README 카드를 만들고 README의 `supporters` 표시 사이 내용을 갱신합니다. 글꼴 파일은 `scripts/lib/fonts/`에 있고 SIL Open Font License 1.1(같은 디렉터리의 `OFL.txt`)로 배포되며 생성 스크립트에서만 사용합니다. 새 아바타는 같은 스크립트로 정사각형으로 잘라 형식을 바꿀 수 있습니다: `node scripts/supporters.mjs --avatar <id> <이미지 파일>`.
