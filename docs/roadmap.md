# 로드맵

## 플랫폼과 하드웨어

- [ ] **macOS 지원**. GPUI 인터페이스와 공유 앱 서비스를 재사용하고 수집, 프로세스 제어, 알림 영역, 바로 가기, 권한, 배포를 맞춥니다.
- [ ] **더 많은 디스크 프로토콜**. 현재의 NVMe 컨트롤러／장치 수준 조회 대체, ATA／SATA, USB-SAT, SCSI／SAS 조회, 주요 SATA SSD 매핑, SATA/PATA HDD의 운용·섹터 통계를 바탕으로 다른 모델과 펌웨어의 SMART 특성 해석을 계속 넓히고, 아직 확정하지 못한 호스트 카운트 단위를 확인하며, 제조사 전용 명령이 필요한 USB／RAID 브리지 장치를 보충합니다.
- [ ] **RAID 컨트롤러 뒤 디스크의 온도**. Intel RST／VMD 등 RAID 계열 컨트롤러 뒤의 디스크는 아직 온도와 NVMe 상태 로그를 조회하지 않습니다. 컨트롤러 드라이버와 버전별로 조회가 정상적으로 응답하는 것을 확인한 범위부터 엽니다.
- [ ] **구형 Intel 통합 그래픽**. 이미 지원하는 Comet Lake S/H를 바탕으로 모델별 레지스터 배치를 넓히고, 드라이버가 보고하는 주파수와 실측 기준 클록의 출처를 확인합니다.
- [ ] **기타 소비자용 하드웨어**. 확정한 인터페이스와 센서 배치에 따라 2010년 이후 모델로 넓힙니다. 현재 적용 범위는 [하드웨어 데이터](guide/hardware-data.md)에 있습니다.

## 인터페이스와 조작

- [ ] **전역 바로 가기 확장**. 좌우 보조키 구분, 보조키만으로 된 조합, 주 키 두 개 조합의 입력 방식을 검토합니다. 관리자 창이 포그라운드에 있을 때의 동작과 전역 입력 지연을 검증합니다. 현재 규칙은 [전역 바로 가기](design/hotkey.md)를 참고합니다.

## 의존성 유지 관리

- [ ] **유지 관리가 중단된 간접 의존성 이전**. `instant`, `paste`, `rustybuzz`, `ttf-parser`를 차례로 처리하고 기존 GPUI 동작을 유지하며 글꼴, 아이콘, 상호 작용, 성능을 다시 확인합니다. 현재 도입 경로와 후보 방안은 [의존성과 보안 유지 관리](development/security.md)를 참고합니다.

현재 기능과 사용 방법은 [사용 가이드](guide/README.md), 이미 배포된 버전의 변화는 [변경 기록](../changelog/ko-KR.md)에 있습니다.
