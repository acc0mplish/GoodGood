# 아키텍처

GoodGood은 Windows x64 네이티브 애플리케이션입니다. `goodgood-core`가 시스템 데이터를 읽고, `goodgood-app`이 샘플링을 조정하고 설정을 관리하며, `src-gpui`가 데스크톱 프로세스 안에서 GPUI Kit로 인터페이스를 그립니다.

| 디렉터리 | 역할 |
|---|---|
| `crates/goodgood-core` | Windows 네이티브 수집, 데이터 모델, 기록과 시스템 작업 |
| `crates/goodgood-service` | 선택적 권한 있는 서비스, 고정 센서 모듈과 작업 관리자 보조 프로그램 |
| `crates/goodgood-app` | 샘플링 조정, 설정, 인터페이스 환경 설정, 작업 시작과 설치 보조 |
| `src-gpui` | GPUI 뷰, 창 수명 주기, 알림 영역, 바로 가기와 업데이트 |
| `resources` | 애플리케이션 메타데이터, 아이콘, 테마, 애니메이션 매개변수와 하드웨어 지표 정의 |
| `tools` | 독립 창 캡처 프로브와 릴리스 서명 도구 |

샘플링 스레드는 전면, 최소화 또는 알림 영역 상태에 따라 간격을 선택합니다. 스냅숏 변환과 프로세스 그룹화는 백그라운드에서 완료되며, 인터페이스는 최신 결과를 받아 현재 정렬과 행 선택을 유지합니다. 곡선은 샘플링 시각을 사용하고, 애니메이션은 디스플레이 주기에 맞춰 그립니다.

파일 잠금 조회와 프로세스 작업은 호스트가 작업 스레드에 배정합니다. 프로세스를 변경하기 전에 PID와 생성 시간을 확인합니다. 커널 권한이 필요한 센서 값은 권한 있는 서비스와 고정 PawnIO 모듈을 통해 가져오며, 없는 값은 알 수 없음으로 표시합니다.
