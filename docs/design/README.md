## 원칙

- **개요와 세부 정보**. 개요 영역은 큰 숫자로 시스템 전체 부하를 표시합니다. 프로세스 표는 고정폭 숫자를 쓰고 표시 정밀도에 따라 정렬합니다. 성능 페이지는 실시간 표시값과 자주 쓰는 사양의 자리를 먼저 잡고 남은 공간에 곡선을 그립니다. CPU 세부 정보는 온도, 전력, 센서를 따로 보여 줍니다.
- **색**. CPU는 청록, E 코어는 페리윙클 블루, LP E 코어는 초록(보라 계열은 적록 색각 이상에서 E 코어의 파랑과 거의 구분되지 않습니다), 메모리는 보라, 디스크는 호박색, 네트워크는 초록, GPU는 로즈 핑크, 배터리는 연두를 씁니다. 선택과 포커스에는 시스템 강조색을, 되돌릴 수 없는 작업에는 코럴 레드를 씁니다.
- **단위**. 용량과 바이트 속도는 1024 단위로, 비트 속도는 1000 단위로 계산합니다. 디스크와 I/O는 바이트/초를 쓰고, 네트워크는 설정의 단위를 따르며, 성능 페이지의 네트워크 보기는 두 단위를 함께 표시합니다.
- **목록 상호 작용**. 포인터가 프로세스 목록에 있거나 메뉴와 확인 대화 상자가 열려 있는 동안 행 위치를 유지하고 값은 계속 갱신합니다. 정렬이 돌아오면 현재 열과 방향에 따라 배치합니다.
- **창과 글자**. Windows 11에서는 Mica와 시스템 강조색을 쓰고 제목 표시줄은 시스템 스냅 레이아웃을 지원합니다. 인터페이스는 Segoe UI Variable과 Malgun Gothic을 씁니다.
- **모션**. 페이지 전환, 대화 상자 열기, 차트 격자 재배치 시 요소가 현재 위치에서 목표 위치로 이동합니다. 실시간 곡선은 샘플 시각에 따라 스크롤하며 캐시한 텍스처를 재사용합니다. 그리기에 영향을 주는 변경은 [성능 측정 방법](../development/performance.md)에 따라 비용을 확인합니다.
- **키보드**. Ctrl+1–9로 페이지를 전환하고, 방향 키로 항목을 선택하거나 펼치며, Enter로 세부 정보를 열고, Ctrl+F로 검색합니다. 다른 조작은 [키보드 조작](../guide/README.md#키보드-조작)을 참고합니다.
