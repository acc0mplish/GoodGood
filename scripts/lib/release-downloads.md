## 다운로드 파일 안내 / Download files

### 한국어

일상적인 사용에는 업데이트와 관리가 쉬운 설치 버전을 권장합니다.

| | 설치 버전(권장) | 무설치 버전 |
|---|---|---|
| **파일** | `GoodGood_{{version}}_x64-setup.exe` | `GoodGood_{{version}}_x64.exe` |
| **사용 방식** | `Program Files`에 설치하며, 설치와 업데이트에 관리자 권한이 필요합니다 | 단일 파일이며, 다운로드 후 바로 실행합니다 |
| **버전 업데이트** | 앱에서 내려받아 설치합니다 | 새 버전만 알리며, EXE를 직접 내려받아 교체해야 합니다 |
| **바로 가기와 제거 항목** | 설치할 때 자동으로 만듭니다 | 없음 |
| **권한 있는 서비스와 작업 관리자 대체**(사용하는 경우) | 버전 업데이트와 함께 자동으로 동기화합니다 | EXE를 교체한 뒤 설정 → 권한에서 “서비스 업데이트”를 클릭합니다 |

- 두 버전은 현재 Windows 계정의 설정과 기록을 함께 사용합니다.
- 권한 있는 서비스와 PawnIO는 선택 구성 요소이며, 설정에서 필요할 때 설치하거나 사용하도록 설정합니다.

### English

The installer is recommended for everyday use, as it is easier to update and maintain.

| | Installer (recommended) | Portable version |
|---|---|---|
| **File** | `GoodGood_{{version}}_x64-setup.exe` | `GoodGood_{{version}}_x64.exe` |
| **Setup** | Installs to `Program Files`; installing and updating require administrator permission | Single executable; runs directly after download |
| **Updates** | Downloaded and installed in the app | Notification only; download and replace the EXE manually |
| **Shortcuts and uninstall entry** | Created during installation | None |
| **Privileged service and Task Manager replacement** (if enabled) | Updated together with GoodGood | After replacing the EXE, click **Update service** in Settings → Permissions |

- Both versions share the settings and history of the current Windows account.
- The privileged service and PawnIO are optional components that can be installed or enabled in Settings as needed.
