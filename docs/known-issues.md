# 알려진 문제

## 기능 제한

- **파일 잠금 조회**는 다시 시작 관리자와 핸들 스캔을 합칩니다. 보호된 프로세스, 닫힌 핸들의 매핑, 스캔 시간 초과, 동시 파일 변경이 결과에 영향을 줄 수 있습니다. 핸들 스캔의 경로 범위와 인터페이스 안내는 [파일을 사용하는 항목](guide/README.md#파일을-사용하는-항목)을 참고합니다.
- **서비스와 시작 프로그램**의 조작 권한은 대상에 따라 다릅니다. 대부분의 시스템 서비스를 관리하거나 모든 사용자의 시작 항목을 바꾸려면 관리자 권한이 필요합니다. 권한 있는 서비스가 수행할 수 있는 작업은 [권한](guide/settings.md#권한)을 참고합니다.
- **작업 관리자 대체**는 권한 있는 서비스 디렉터리의 GoodGood 사본을 시작합니다. 포터블 버전을 직접 바꾸었거나 설치 관리자가 서비스 업데이트에 실패한 뒤에는 새 버전의 “설정 → 권한”에서 “서비스 업데이트”를 클릭해 Ctrl+Shift+Esc가 새 사본을 열게 합니다. 포터블 프로그램을 바꾸기 전에 알림 영역에서 이전 버전을 종료합니다.
- **프로세스별 네트워크 트래픽**에는 사용 가능한 로컬 ETW 세션 또는 권한이 부여된 권한 있는 서비스가 필요합니다. 서비스 표시값은 백그라운드로 전달되므로 보통 로컬 샘플링보다 새로 고침 주기 하나만큼 늦습니다. 두 원본을 모두 쓸 수 없으면 인터페이스가 네트워크 열을 숨깁니다.
- **기록**은 CPU, 메모리, I/O, GPU, 네트워크 사용량을 기준으로 시점마다 가장 사용량이 많은 프로세스를 저장하며 프레임당 최대 21개입니다. 현재 실행 중인 다른 프로세스를 찾을 때는 프로세스 페이지를 사용합니다. 기록 간격은 [기록](guide/README.md#기록)을 참고합니다.
- **전역 바로 가기**는 보조키 한 묶음과 주 키 하나로 일치를 판단하며 좌우 보조키를 같은 키로 봅니다. 기록 규칙과 예약 조합은 [설정](guide/settings.md#키보드-바로-가기)을 참고합니다.
- **하드웨어 센서**의 적용 범위는 모델, 펌웨어, 드라이버에 따라 다릅니다. AMD 코어별 온도는 매핑된 SMU 필드가 필요하고, 메인보드 팬은 하드웨어 채널 번호로 표시합니다. 표시값 출처와 적용 모델은 [하드웨어 데이터](guide/hardware-data.md)를 참고합니다.
