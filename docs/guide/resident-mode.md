# 상주 모드, 알림 영역과 바로 가기

- 창을 닫을 때 기본으로 알림 영역에 남습니다. 알림 영역 아이콘을 클릭하거나 **Ctrl+Alt+Esc**를 눌러 창을 표시하거나 숨깁니다. 클릭할 때는 창을 다른 창이 가리고 있지 않으면 숨기고, 바로 가기를 누를 때는 창이 현재 사용 중인 창일 때 숨깁니다. 창이 가려져 있거나 최소화되었거나 다른 가상 데스크톱에 있으면 맨 앞에 표시합니다. 바로 가기는 [설정](settings.md#키보드-바로-가기)에서 바꾸거나 끌 수 있습니다. 알림 영역 아이콘이 키보드 포커스를 받으면 Enter나 스페이스로도 창을 표시하거나 숨깁니다.
- 알림 영역 관련 설정은 [구성 요소](#구성-요소-페이지) 페이지(Ctrl+7)에 모여 있습니다.
- 알림 영역에 숨기면 인터페이스는 그리기를 멈추고 수집, 기록, 규칙은 계속 실행됩니다. 알림 영역 상태와 최소화 상태는 샘플링 간격이 따로 있고 모두 기본값이 5초입니다. 간격이 5초를 넘으면 기록도 그 간격으로 씁니다. 자세한 내용은 [데이터 및 기록](settings.md#데이터-및-기록)을 참고합니다.
- 숨기거나 최소화한 지 기본으로 10분이 지나면 GoodGood이 차트 이미지를 해제하고 쓰지 않는 메모리를 돌려주며, 창을 다시 표시하면 차트를 다시 그립니다. 시간은 [데이터 및 기록](settings.md#데이터-및-기록)에서 조정하거나 끌 수 있습니다.
- 같은 인스턴스를 다시 시작하면 이미 있는 창이 표시됩니다.
- 설정에서 Windows 로그인 시 시작을 켤 수 있습니다. `--hidden` 매개 변수로 시작해 조용히 알림 영역으로 들어갑니다.
- [관리자 권한으로 실행](settings.md#권한)을 켜면 위의 진입점이 모두 같은 권한 부여를 따르고, 로그인 시 시작은 여전히 숨김 상태를 유지합니다. 이 권한 부여는 권한 있는 서비스와 별개입니다.

## 알림 영역 아이콘

알림 영역 아이콘은 기본값이 “추세”입니다. GoodGood 로고의 각 열이 샘플 하나에 해당하고 그때의 CPU 사용량만큼 아래에서 위로 점을 켜며, 가장 오른쪽 열이 최신 샘플이고 강조색으로 표시합니다. “비율”로 바꾸면 현재 사용량만큼 점을 켭니다(아이콘이 16–24 px일 때 점이 모두 25개이고 점마다 4%를, 32 px일 때는 100개이고 점마다 1%를 뜻합니다). 사용률 백분율을 보여 주는 “숫자”로 바꾸거나 앱 아이콘으로 되돌릴 수도 있습니다. 사용량이 80%에 이르면 최신 열, 켜진 점, 숫자가 호박색으로 바뀝니다. 로고와 숫자는 작업 표시줄의 밝고 어두운 테마에 따라 흰색이나 검은색으로 바뀌어 시스템 아이콘과 맞춥니다. 아이콘은 현재 새로 고침 간격에 맞춰 갱신되며, 창이 표시되어 있으면 “새로 고침 빈도”를, 알림 영역에 숨겨져 있으면 “알림 영역에서의 새로 고침 빈도”를 따릅니다. 추세는 갱신할 때마다 한 열씩 왼쪽으로 밀립니다.

새 버전이 준비되면 아이콘에 강조색 점이 표시됩니다. 추세는 로고 제목 표시줄 오른쪽에, 비율은 오른쪽 위의 점 하나를 대신해, 숫자는 오른쪽 위에, 앱 아이콘은 오른쪽 아래에 표시합니다.

알림 영역 아이콘은 같은 프로그램 경로에서 안정적인 식별자를 유지하므로 Windows가 같은 아이콘으로 작업 표시줄이나 접힌 영역의 표시 위치를 보존할 수 있습니다. 이전 버전 식별자에서 처음 이전할 때는 아이콘을 접힌 영역 밖으로 한 번 다시 끌어내야 할 수 있습니다.

## 마우스 올림 카드와 빠른 패널

포인터를 알림 영역 아이콘에 머무르면 마우스 올림 카드가 표시됩니다. CPU, 메모리, GPU 사용량과 네트워크 받기·보내기 속도, 클릭과 마우스 오른쪽 단추 클릭의 동작이 들어 있습니다. “마우스 올림 카드”를 끄면 시스템 도구 설명으로 바뀌어 CPU와 메모리 사용량을 표시합니다.

알림 영역 아이콘을 마우스 오른쪽 단추로 클릭하면(또는 아이콘이 포커스를 받은 상태에서 메뉴 키를 누르면) 기본으로 빠른 패널이 열리고 알림 영역 아이콘 옆, 작업 표시줄 위에 놓입니다.

- 위쪽에 버전 번호가 있고 새 버전이 있으면 업데이트 진입점을 표시하며 “업데이트”를 클릭하면 업데이트 대화 상자가 열립니다.
- CPU, 메모리, GPU, 네트워크 네 가지 표시값이 각각 최근 60회 샘플의 곡선과 함께 있습니다. 한 항목을 클릭하면 성능 페이지의 해당 장치가 열립니다.
- CPU 사용량이 가장 높은 프로세스 세 개를 표시하고 클릭하면 프로세스 페이지에서 그 프로세스로 이동합니다.
- 아래쪽에 “GoodGood 열기”, 업데이트 일시 중지 / 다시 시작, 알림 영역 설정(구성 요소 페이지 열기), “GoodGood 종료”가 있습니다.

패널 바깥을 클릭하거나 Esc를 누르면 닫히고, 알림 영역 아이콘을 다시 마우스 오른쪽 단추로 클릭해도 닫힙니다. 알림 영역 아이콘이 “숨겨진 아이콘 표시” 영역에 있으면 카드와 패널이 그 영역 위에 표시되어 가리지 않습니다. 패널을 열거나 포인터를 패널로 옮기거나 패널의 단추를 클릭하면 숨겨진 아이콘이 펼쳐진 채 유지되고, 다른 곳을 클릭하거나 Esc를 누르면 둘이 함께 닫힙니다. “알림 영역 아이콘을 마우스 오른쪽 단추로 클릭할 때”를 “메뉴”로 바꾸면 “GoodGood 열기”와 “버전 {version} 준비됨”(새 버전이 준비되었을 때), “GoodGood 종료”만 나열합니다.

마우스 올림 카드나 빠른 패널이 열려 있는 동안에는 창이 표시될 때의 “새로 고침 빈도”로 샘플링하고 표시값과 곡선도 함께 갱신하며, 닫으면 알림 영역 상주 시의 간격으로 돌아갑니다. 카드와 패널은 인터페이스 테마를 따르고, “창 전환 효과”를 켜고 Windows 애니메이션 효과를 켜 두었으면 나타나고 사라질 때 페이드합니다.

## 데스크톱 모니터

데스크톱 모니터는 선택한 표시값을 데스크톱의 작은 창에 보여 주며 기본값은 꺼짐이고 [구성 요소 페이지](#구성-요소-페이지)에서 켭니다. 구성 요소 페이지의 “표시할 항목”은 표 하나와 같습니다. 왼쪽 열은 장치와 장치를 구분하는 정보이고 오른쪽은 그 장치에서 고를 수 있는 표시값입니다. 데스크톱 모니터와 작업 표시줄 모니터는 표의 순서대로 표시합니다.

| 장치 | 표시값 |
|---|---|
| CPU | 사용률(기본값), 온도, 클록, 전력 |
| 메모리 | 백분율(기본값), 사용량(GB) |
| GPU | 사용률(기본값), 온도, 메모리, 클록, 전력, 팬 |
| 디스크 | 읽기 및 쓰기(기본값), 활성 시간, 온도 |
| 네트워크 | 받기 및 보내기(기본값) |
| 기타 | 배터리 충전 수준, 가동 시간 |

그래픽 카드, 디스크, 네트워크 어댑터가 여러 개 감지되면 표에 장치마다 한 행이 따로 나오고 각각 고를 수 있습니다.

- 디스크는 드라이브 문자(문자가 없으면 “디스크 {index}”), 모델, 용량을 나열하고, 네트워크 어댑터는 연결 이름과 어댑터 모델을, 그래픽 카드는 이름과 전용 메모리를 나열합니다.
- 디스크와 네트워크 어댑터의 첫 행은 “모든 디스크”, “모든 네트워크 어댑터”입니다. 읽기·쓰기 속도와 받기·보내기 속도는 합계이고 디스크 활성 시간과 온도는 가장 높은 디스크를 씁니다. 디스크나 어댑터가 하나뿐이면 이 행만 표시합니다.
- 그래픽 카드의 첫 행은 기본 그래픽 카드(전용 메모리가 가장 많은 카드)이고, 그래픽 카드를 지정하지 않은 표시값은 이 카드에서 가져옵니다.
- 선택한 장치는 모델과 이름으로 기억되어 다시 시작하거나 다시 연결해도 같은 장치를 가리킵니다. 장치가 끊기면 표시값이 대시로 바뀌고 표에는 “연결되지 않음” 장치 행이 남아 선택을 해제할 수 있습니다.
- 지정한 장치의 표시값은 데스크톱 모니터에서 장치 이름으로 시작하고(예: “C: 온도”, “UHD Graphics 770 사용률”) 속도 행은 장치 이름을 제목으로 씁니다. 작업 표시줄에서는 드라이브 문자, 연결 이름, GPU1／GPU2로 구분합니다.

백분율, 온도, 충전 수준에는 진행 막대가 하나씩 붙고 클록, 전력, 팬, 가동 시간은 값만 표시합니다. 사용률과 CPU·GPU 온도가 80%(80 °C)에 이르면 값과 진행 막대가 호박색으로 바뀝니다. 디스크 온도는 디스크가 보고한 경고 온도에 이르면 색이 바뀌고 보고하지 않으면 70 °C를 기준으로 하며, 배터리는 전원이 연결되지 않았고 충전 수준이 20% 이하일 때 색이 바뀝니다. 디스크와 네트워크는 읽기와 쓰기, 받기(↓)와 보내기(↑) 속도를 표시하고 네트워크 속도의 단위는 “네트워크 속도 단위” 설정을 따릅니다. 그래픽 카드 표시값은 전용 메모리가 가장 많은 카드에서 가져오고, 실측 전력이 없으면 전력 예산 대비 비율(`% TDP`)을 표시합니다. 디스크 활성 시간은 가장 사용량이 많은 디스크에서, 디스크 온도는 가장 뜨거운 디스크에서 가져오며, CPU 전력은 패키지 전력을 쓰고 없으면 코어 전력을 씁니다. 표시값이 없으면 대시를 표시합니다.

- 처음 켜면 기본 디스플레이 작업 영역의 오른쪽 위에 표시됩니다. 아무 곳이나 누르고 있으면 끌 수 있고 놓으면 위치를 기억합니다. 그 위치의 디스플레이가 끊기면 다시 기본 디스플레이 오른쪽 위에 표시됩니다.
- 클릭해도 작은 창은 포커스를 받지 않고 현재 창이 활성 상태로 남습니다. 두 번 클릭하면 GoodGood이 열리고, 마우스 오른쪽 단추로 클릭하면 메뉴가 열립니다. 메뉴에는 “GoodGood 열기”, “항상 위”, “위치 고정”, “구성 요소 설정…”, “데스크톱 모니터 끄기”가 있습니다.
- 기본으로 항상 위에 표시되고, 끄면 다른 창과 층서 순서대로 배열됩니다. 위치를 고정하면 끌 수 없습니다.
- “클릭 통과”를 켜면 클릭과 끌기가 아래에 있는 창에 작용하고 작은 창은 포인터에 반응하지 않으며 구성 요소 페이지에서만 이 항목을 끌 수 있습니다.
- 불투명도는 100%(기본값), 90%, 80%, 70%, 60% 중에서 고를 수 있고 작은 창 전체에 적용됩니다.
- 작은 창은 인터페이스 테마와 언어를 따릅니다.

## 작업 표시줄 모니터

작업 표시줄 모니터는 기본 디스플레이의 작업 표시줄에 선택한 표시값을 보여 주며 기본값은 꺼짐이고 [구성 요소 페이지](#구성-요소-페이지)에서 켭니다. 기본으로 CPU, 메모리, 네트워크를 표시하며 고를 수 있는 항목은 데스크톱 모니터와 같습니다. 글자 색은 작업 표시줄의 밝고 어두운 테마를 따라 알림 영역 아이콘과 같아지고, 값이 80%(온도는 80 °C)에 이르면 호박색으로 바뀝니다. 레이블, 곡선, 큰 숫자 스타일은 값이 가질 수 있는 최대 너비로 표시값마다 자리를 확보하므로 값이 바뀌어도 위치가 움직이지 않습니다. 구성 요소 페이지의 “스타일”은 네 가지 표시 방식을 제공합니다.

| 스타일 | 표시 방식 |
|---|---|
| 레이블(기본값) | 이름이 왼쪽, 값이 오른쪽으로 두 줄로 놓입니다. 값이 하나인 표시값은 차례로 둘씩 짝지어 열을 이루고 디스크와 네트워크의 두 속도는 각각 한 열을 차지합니다. 작업 표시줄이 두 줄 글자에 필요한 높이보다 낮으면 한 줄로 놓입니다. |
| 곡선 | 항목마다 옅은 작은 카드를 둡니다. 이름과 값이 위에 있고 아래에 최근 40회 샘플의 추세가 있으며, 곡선은 장치의 색(CPU 청록, 메모리 보라, GPU 핑크, 디스크 호박색, 네트워크 초록)을 쓰고 값이 높으면 호박색으로 바뀝니다. 백분율과 온도는 100을 기준으로 하고, 속도는 이 구간의 최대값(최소 1 MB/s이며 유휴 상태에서는 곡선이 바닥에 가깝습니다)을 기준으로 하며, 클록·전력·팬은 이 구간의 최소값과 최대값 사이로 환산해 변화를 볼 수 있게 합니다. |
| 캡슐 | 항목마다 둥근 캡슐을 한 줄로 늘어놓습니다. 장치 색 점, 이름, 바로 뒤에 값이 붙습니다. 디스크와 네트워크의 두 속도는 캡슐 하나를 함께 쓰고 각각 장치 색 화살표 뒤에 붙입니다. 캡슐은 최근 1분 안의 가장 넓은 값으로 너비를 정합니다. 값이 넓어지면 바로 넓히고 좁아지면 1분 뒤에 좁힙니다. |
| 큰 숫자 | 항목마다 칸 하나를 둡니다. 장치 색의 작은 이름이 위에 있고 큰 숫자가 아래에서 이름과 왼쪽을 맞추며, 단위는 작게 줄이고 흐리게 합니다. 디스크와 네트워크의 두 속도는 두 줄로 놓습니다. |

곡선, 캡슐, 큰 숫자는 두 줄 글자 높이가 필요하고 작업 표시줄이 낮으면 레이블로 표시합니다.

- 기본으로 알림 영역 옆에 놓입니다. Windows 11에서 작업 표시줄 단추가 가운데 정렬이면 “왼쪽”으로 바꿀 수 있고, 위젯 단추를 켜 두었으면 그 자리를 비켜 줍니다. Windows 10의 작업 표시줄은 빈자리가 없어 작업 단추 영역이 표시값 너비만큼 좁아지고, 작업 표시줄 모니터를 끄거나 GoodGood을 종료하면 되돌아옵니다.
- 클릭하면 알림 영역 아이콘을 클릭할 때와 같이 창을 표시하거나 숨깁니다. 포인터가 머무르면 배경색만 표시하고 마우스 올림 카드는 표시하지 않습니다.
- 마우스 오른쪽 단추로 클릭하면 작업 표시줄 모니터 위에 그 패널이 열립니다. “스타일”의 네 카드는 선택한 앞의 두 표시값으로 각 스타일의 실제 모습을 보여 주고 클릭하면 바로 바뀝니다. “표시할 항목”은 CPU, 메모리, GPU, 디스크, 네트워크, 기타로 나뉘어 나열되고 구성 요소 페이지와 항목이 같으며, 선택한 표시값은 그 장치의 작업 표시줄 색으로 표시됩니다. GPU와 디스크의 장치가 여러 개이면 레이블로 장치를 바꾸고, 레이블의 점은 그 장치에 선택한 표시값이 있음을 뜻하며 포인터를 올리면 모델을 표시합니다. 네트워크 어댑터는 각각 한 항목입니다. 아래쪽에 “구성 요소 설정…”과 “작업 표시줄 모니터 끄기”가 있습니다. 스타일을 바꾸거나 표시값을 선택하는 동안 패널이 열린 채로 유지되고 변경은 작업 표시줄에 바로 표시되고 저장됩니다. 패널 바깥을 클릭하거나 Esc를 누르거나 작업 표시줄 모니터를 다시 마우스 오른쪽 단추로 클릭하면 닫힙니다.
- 탐색기를 다시 시작하면 작업 표시줄로 자동으로 돌아옵니다. 세로 작업 표시줄에서는 작업 표시줄 모니터를 표시하지 않습니다.

데스크톱 모니터나 작업 표시줄 모니터가 표시되는 동안에는 창을 알림 영역에 숨겨도 “새로 고침 빈도”로 샘플링하고 표시값도 창이 표시될 때와 같이 갱신됩니다.

## 구성 요소 페이지

구성 요소 페이지는 알림 영역, 데스크톱 모니터, 작업 표시줄 모니터 설정을 한곳에 모으고 예정된 다이내믹 아일랜드도 나열합니다.

| 설정 | 설명 |
|---|---|
| 알림 영역 아이콘 | 앱 아이콘, 추세(기본값), 비율, 숫자 중에서 고릅니다. [알림 영역 아이콘](#알림-영역-아이콘)을 참고합니다. |
| 마우스 올림 카드 | 기본값은 켜짐입니다. [마우스 올림 카드와 빠른 패널](#마우스-올림-카드와-빠른-패널)을 참고합니다. |
| 알림 영역 아이콘을 마우스 오른쪽 단추로 클릭할 때 | 빠른 패널(기본값) 또는 메뉴. |
| 닫을 때 알림 영역에 유지 | 기본값은 켜짐입니다. 창을 숨긴 동안 “알림 영역에서의 새로 고침 빈도”(기본값 5초)로 샘플링하고 기록과 규칙은 그대로 진행합니다. 이 항목을 끄면 창을 닫을 때 GoodGood이 종료됩니다. |
| 알림 영역에서 다시 열기 | 기본값은 “현재 페이지 유지”이고 “기본 페이지 열기”로 바꿀 수 있습니다. 창을 알림 영역에 숨긴 뒤 바로 가기, 알림 영역 아이콘, 빠른 패널, 알림 영역 메뉴, 다시 시작으로 다시 열 때 적용되며, 최소화 복원과 이미 표시된 창의 활성화는 현재 페이지를 유지합니다. 닫지 않은 대화 상자가 있으면 작업을 이어 갈 수 있게 원래 페이지를 유지합니다. 페이지 안의 필터와 정렬은 계속 유지됩니다. |
| 알림 영역에서의 새로 고침 빈도 | 알림 영역에 숨겼을 때(부팅 후 창을 열지 않은 상태 포함)의 샘플링 간격으로 0.5초, 1초, 2초, 5초(기본값), 10초, 30초입니다. 알림 영역 아이콘과 시스템 도구 설명도 이 간격으로 갱신됩니다. 간격이 길수록 백그라운드 비용이 줄지만 새로 시작된 프로그램에 규칙이 적용되기까지 최대 한 간격이 걸리고, 5초보다 길면 기록도 드물어집니다. |

설정 페이지 “시작 프로그램 및 알림 영역” 그룹의 “알림 영역과 구성 요소” 카드에서 이 페이지를 바로 열 수 있습니다.

알림 영역 상주 시의 CPU, GPU, 메모리 비용을 측정하는 방법은 [성능 측정](../development/performance.md)을 참고합니다.
